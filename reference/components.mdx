## Core Components

### Player

The main audio player component that handles playback, controls, and state management.

**Location:** `src/components/player.tsx:27`

<ParamField path="playlist" type="Playlist" required>
  Array of playlist items containing surah information and audio links
</ParamField>

**Features:**
- Audio playback with play/pause controls
- Shuffle and repeat modes
- Volume control
- Playback speed adjustment
- Fullscreen mode
- Media session integration
- Sleep timer

<CodeGroup>
```tsx Usage
import Player from '@/components/player';
import { Playlist } from '@/types';

const playlist: Playlist = [
  { surahId: '1', link: 'https://example.com/001.mp3' },
  { surahId: '2', link: 'https://example.com/002.mp3' },
];

<Player playlist={playlist} />
```

```tsx Example
'use client';
import { Player } from '@/components/player';
import { useAtomValue } from 'jotai';
import { selectedReciterAtom } from '@/jotai/atom';

export default function PlayerPage() {
  const selectedReciter = useAtomValue(selectedReciterAtom);
  const playlist = selectedReciter?.moshaf?.playlist || [];
  
  return <Player playlist={playlist} />;
}
```
</CodeGroup>

### Range

Custom range slider for seeking through audio tracks.

**Location:** `src/components/range.tsx:12`

<ParamField path="currentTime" type="number" required>
  Current playback position in seconds
</ParamField>

<ParamField path="duration" type="number" required>
  Total track duration in seconds
</ParamField>

  Callback to update current time
</ParamField>

<ParamField path="audioRef" type="React.RefObject<HTMLAudioElement | null>" required>
  Reference to the audio element
</ParamField>

**Features:**
- RTL support (direction-aware gradient)
- Smooth gradient fill showing progress
- Custom thumb styling
- Synchronized with audio element

<CodeGroup>
```tsx Usage

const [currentTime, setCurrentTime] = useState(0);
const [duration, setDuration] = useState(0);

<Range
  currentTime={currentTime}
  duration={duration}
  setCurrentTime={setCurrentTime}
  audioRef={audioRef}
/>
```
